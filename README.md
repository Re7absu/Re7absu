# Hi, I'm Rehab Bakhet

I'm a Computer Science graduate working in Python across backend development, data engineering, data analysis and machine learning. I like building things that move data from where it is to where it's useful: APIs, automated pipelines, and models that answer a concrete question.

My recent work includes a full-stack job-search assistant (FastAPI, PostgreSQL, Next.js), a survival-analysis model for wildfire evacuation risk built for the WiDS Datathon 2026, and smaller projects in SQL, data cleaning and data ingestion.

## What I work on

- **Backend development:** REST APIs with FastAPI, relational data models, migrations, authentication, and integrations with external APIs.
- **Data engineering:** ingesting data from APIs, cleaning and validating it, and loading it into PostgreSQL.
- **Data analysis:** turning raw tables into clear answers with pandas and SQL.
- **Machine learning:** framing the problem correctly, evaluating honestly, and explaining the limits of a model.
